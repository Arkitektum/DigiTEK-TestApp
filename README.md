# DigiTEK-TestApp
App'en er en PoC - utviklet av Arkitektum for DiBK - som et testverktøy for verifisering av regelendringer implementert i Camunda DMN og BPMN. 
PoC'en var en del av løsningsutforskningen DigiTEK, som undersøkte mulighetene for å digitalisere kvantitative regler i TEK17, kapitlet om "Sikkerhet ved brann". Etter at man har gjort endringer i DMN, eller i BPMN prosessformuleringen, kan man med app'en verifisere og dokumentere hvordan endringene slår ut, om de fungerer og er i tråd med forventningene.
